Dendro · BPTT_fix vs BPTT_fix_auto

Where the two backward passes diverge

Both rules run the same forward pass and read out the same loss. Only the gradient differs. Here is the chain rule, term by term, for a two-hidden-layer network — and the exact three places the hand-derived rule departs from what autodiff computes.

Network x → L1 → L2 → readout L1, L2 two-compartment (soma + dendrite) Readout leaky integrator, mean-voltage softmax CE Shared config · two_comp_neuron · lif_neuron (byte-identical) Differs only network.py
soma edge Ws — same time t, kept by both rules dendrite edge Wd — jumps to plateau onset t′, pruned inter-layer by the hand rule within-layer time recurrence — exact backprops it, e-prop truncates it

The whole story in three differences

Set the loss ℓ and the forward pass aside for a moment. Given identical spikes, the exact gradient (BPTT_fix_auto, one scalar loss through jax.grad) and the hand rule (BPTT_fix, two forward passes, no autodiff) can differ in only three ways. Every term below is one of these three colors.

#1 The inter-layer dendrite edge is pruned

A spike ol−1 reaches the next layer through two edges: the same-time soma edge, and a dendrite edge that jumps to the plateau-onset time t′. Exact BPTT credits both. The hand rule transports error between layers through the soma weights only — the dendrite is descended into locally (to train Wdl) but carries no error back to ol−1. This difference does not exist in a one-hidden-layer net — it needs a layer below to feel the missing edge.

#2 Time credit: backward adjoint → forward eligibility

Exact BPTT backpropagates through the αs/αd membrane recurrences, the reset v = vpre(1−o), and adaptation. The hand rule replaces that entire backward-in-time chain with forward eligibility traces (e-prop). Iterated across a plateau the exact recurrence has spectral radius > 1, so its gradient explodes exponentially; the e-prop trace stays bounded.

#3 Two deliberate rescalings

The hand rule drops the softmax 1/temperature factor everywhere and divides the soma gradient by _SOMA_GRAD_SCALE = 8. Pure magnitude — undo them and the direction is unchanged. Below, “fix (norm)” means the hand gradient with these undone.

§1

The forward pass — identical for both

One hidden layer l at step t, with presynaptic input ol−1[t] (or the raw input x[t] for l = 1). Two compartments feed one spike. Both folders compute exactly this; the predictions match bit-for-bit.

dendrite — integrate, latch a plateau μl[t] = αd μl[t−1] + (1 − hl[t−1]) · (Wdl ol−1[t])
hl[t] = Θ( μ̂l[t] − μth ) · 𝟙[ 0 ≤ t − t′ ≤ Tp ]   — μ̂ = μ frozen at onset t′; latches for Tp steps
soma — integrate, fire, reset, adapt vprel[t] = αs vl[t−1] + Wsl ol−1[t] − wadaptl[t]
ol[t] = Θ( vprel[t] + γ hl[t] − vth )   — a plateau lowers the threshold by γ
vl[t] = vprel[t] (1 − ol[t])   — hard reset on spike
readout — leaky integrator, no threshold, then loss vr[t] = αm vr[t−1] + Wr oL[t]  ·  mean_v = (1/T) Σt vr[t]
p = softmax( mean_v / τ + b )  ·  ℓ = − Σ target · log p

Two hard thresholds Θ are the only non-differentiable steps. Both rules give them the same surrogate slope, σ(z) = 1 / (1 + β|z|)². Write s′s = σ(vpre+γh−vth) and s′d = σ(μ̂−μth). From the spike equation, the two local derivatives that matter are:

∂ol/∂vprel = s′s      ∂ol/∂hl = γ s′s      ∂hl/∂μ̂l = s′d

Integer routing — t′, the timing gate 𝟙[·] — carries zero gradient in both, exactly as in exact BPTT with a surrogate. Everything up to here is shared. From now on the two rules differ.

§2

The exact chain rule — what autodiff computes

Reverse mode walks the loss backward. Start at the top and descend; nothing is pruned.

Loss → readout → the spikes of the top layer

Because mean_v averages vr and vr leaks with αm, unrolling the readout gives a spike at time t a weight that sums its entire future decay. That geometric sum is exactly the ρ[t] the hand rule precomputes — so the readout adjoint is closed-form and identical in both:

error signal & readout weighting e = target − p  ·  ∂ℓ/∂mean_v = −e / τ  ·  ρ[t] = (1/T) Σs ≥ t αms−t = (1/T) (1 − αmT−t) / (1 − αm)
∂ℓ/∂oL[t] ⊃ −(1/τ) ρ[t] Wr⊤ e   (the readout contribution; downstream layers add more)

Into a layer: the spike, the two compartments, and time

The adjoint of a spike ol[t] splits at the spike equation into a soma branch and a plateau branch, and — this is the part that matters — the soma branch also accumulates a backward-in-time chain, because vprel[t] fed forward into vprel[t+1] (through αs), into the reset, and into adaptation:

soma adjoint — instantaneous term + backward-in-time recurrence λvl[t] ≡ ∂ℓ/∂vprel[t] = (∂ℓ/∂ol[t]) s′s[t] + αs λvl[t+1] (1 − ol[t]) + (reset & adaptation terms)

The blue term is instantaneous and local. The red term reaches back from the future — and it is a recurrence: to get λv[t] you already needed λv[t+1]. Composed step after step through a latched plateau, its per-step Jacobian has magnitude > 1, so the adjoint grows geometrically as the plateau lengthens. This is the exploding gradient.

Between layers: both edges

Now push from layer l down to ol−1. The presynaptic spike entered layer l twice — as soma drive and as dendrite drive — so its adjoint collects both transposed weights:

exact inter-layer transport — soma edge + dendrite edge ∂ℓ/∂ol−1[t] = (Wsl)⊤ λvl[t] + (Wdl)⊤ λμl[t]

where λμl routes back through γ s′s · s′d and the plateau’s t→t′ scatter. Follow both edges across L layers and you get a binary tree of 2L root-to-leaf paths, each with its own t′ time-shift. Finally the weight gradients are outer products of an adjoint with the presynaptic activity:

∂ℓ/∂Wsl = Σt λvl[t] ⊗ ol−1[t]   ·   ∂ℓ/∂Wdl = Σt λμl[t] ⊗ ol−1[t′]
§3

The hand rule — aligned to §2, term by term

BPTT_fix runs the forward twice: pass 1 gets the error e; pass 2 re-runs the forward and accumulates gradients through a soma-only backbone, contracting an instantaneous learning signal against forward eligibility traces. Line it up against §2:

Top rung — identical

δoL[t] = ρ[t] (Wr⊤ e)

Same ρ[t] as the exact readout adjoint. Matches up to the #3 1/τ.

Spike → soma — instantaneous only

Lvl[t] = δol[t] · s′sl[t]

This is §2’s blue term with the red backward-in-time recurrence dropped. #2

inter-layer transport — soma backbone only (dendrite edge dropped) #1 δol−1[t] = (Wsl)⊤ Lvl[t]  + (Wdl)⊤ λμl[t]  ← pruned
weight gradients — instantaneous signal ⊗ forward eligibility (e-prop) #2 Esl[t] = Σs ≤ t αst−s ol−1[s]   — forward somatic eligibility (spreads credit forward, not back)
grad Wsl = Σt Lvl[t] ⊗ Esl[t] / 8  ·  grad Wdl = Σt (Lvl[t] γ s′dl[t]) ⊗ P̂l[t]

P̂l is the dendritic eligibility frozen at the plateau onset t′ (dmu_dw_at_tprime). Notice the dendrite gradient still carries γ s′d: the dendrite reaches the output only through the soma spike, so it must ride on Lv (= δo·s′s), not bare δo. The dendrite is trained; it just can’t pass error to the layer below it.

Why swapping the backward adjoint for a forward trace matters

Exact BPTT contracts a backward-accumulated adjoint λv[t] against ol−1[t]. The hand rule contracts the instantaneous signal Lv[t] against a forward-accumulated eligibility Es[t]. They are transpose-like approximations of the same temporal credit — but e-prop simply omits the reset/adaptation adjoint whose composition blows up. That is the entire reason one gradient stays ~O(1) and the other reaches 1010.

Which difference dominates when? The readout is identical up to #3. In a single hidden layer only #2 and #3 can appear — #1 is invisible because there is no layer beneath to receive the missing edge. Add a second hidden layer and #1 switches on for every layer that is not the top one.

§5

Measured on a real two-layer net

analysis/compare_backward.py builds one 3 → 6 → 6 → 2 network and hands the identical weights to both rules. To isolate #1 by itself it adds a third gradient — auto_prune: exact autodiff, but with the inter-layer dendrite input stop_gradient’d, so it prunes exactly what the hand rule prunes while keeping the exact time adjoint. The decomposition then reads cleanly:

  • auto_full ↔ auto_prune — isolates #1, the pruned dendrite edge.
  • auto_prune ↔ fix (norm) — isolates #2, the e-prop time truncation.
  • fix ↔ auto_full — the total.

A sharper reading of “#2” than magnitude alone

At the top layer, even after removing the prune and the rescalings, the direction agreement between the e-prop and exact gradients is only cos ≈ 0.09. Once the plateau recurrence dominates, e-prop is not a rescaled exact gradient — the two point almost orthogonally. The hand rule’s case is not “approximately the same gradient,” it is “a different, bounded, still-descending gradient.”
